# DeDge DeepSeek Harness v0.1.41 test build

## Changed

- Source-editor selections are saved as managed `editor-selection.txt` attachments that can be opened directly in VS Code.
- Current-file compiler and language-service errors and warnings are saved as an openable diagnostics attachment.
- Rendered preview selections now produce a clear limitation notice instead of silently doing nothing.
- Added separate collapse-all and expand-first-level toolbar buttons.
- Loaded earlier history can be hidden again without deleting the Harness transcript.
