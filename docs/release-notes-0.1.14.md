# DeDge DeepSeek Harness v0.1.14

- Added Queue, Steer, and Auto delivery modes plus Edit and Steer actions on active user messages.
- Made the runtime overlay follow the configured provider and model instead of injecting a fixed DeepSeek model list.
- Reduced settings control density and fixed the UI preview bootstrap.

The bundled Harness runtime remains `0.1.0-rc.7`.
